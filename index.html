SPS Master Control
Overview Privacy

Private owner-operated desktop application

Control and recovery evidence for one SPS estate.

SPS Master Control is a Windows application used by its owner to inspect the state of registered Google Sheets and Apps Script resources, verify backups and recovery evidence, and run explicitly authorized development backup operations.

This page does not offer public access, downloads, accounts, or sign-up.

Google access

Purpose-limited by design

01

Read-only observation

The normal connection uses read-only Google permissions to inspect owner-registered Drive metadata, spreadsheet structure and data, and Apps Script projects when the owner requests a read or validation.

02

Separate privileged authority

Development backup operations use a separate authorization and require the application’s security checks. Protected production, GOLDEN Source, and FINAL boundaries are not made writable by the public website or the read-only connection.

03

Local custody

Google authorization records and application evidence remain under the owner’s control on the owner’s computer or in the owner’s Google account. This website receives none of that data.

Public disclosure

What happens to Google data

Google data is used only to provide owner-requested SPS inventory, validation, backup, recovery, and security evidence. It is not sold, used for advertising, used to build user profiles, or sent to an SPS-operated cloud service.
